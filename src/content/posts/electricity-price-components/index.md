“每度电多少钱”看似简单，却可能指交易价格、零售套餐价格，也可能指总电费除以总电量后的综合单价。比较之前，必须先统一口径。

## 先分清价格和费用

- **价格**通常表达单位电量或单位容量对应的收费标准。
- **电费**是按计量结果、适用标准和调整项目计算后的金额。
- **到户综合单价**可以由总电费除以电量得到，但它未必是某一项合同电价。

固定或容量相关费用存在时，即使每项收费标准不变，用电量变化也可能改变综合单价。

## 五类基础费用

2023 年第三监管周期输配电价通知列出了工商业用户电价的主要组成：上网电价、上网环节线损费用、输配电价、系统运行费用、政府性基金及附加。这可作为理解账单分类的参考，不应把其中费率直接用于其他执行期。[发改价格〔2023〕526 号](https://zfxxgk.ndrc.gov.cn/wap/iteminfo.jsp?id=20233)

| 类别 | 在买什么或承担什么 | 阅读账单时看什么 |
| --- | --- | --- |
| 电能量费用 | 电本身及合同约定的购电安排 | 分时价格、电量、零售合同口径 |
| 输配电费 | 网络使用和容量相关服务 | 电压等级、单一制或两部制 |
| 上网环节线损费用 | 输送过程相关损耗成本 | 适用计算方法及是否已包含 |
| 系统运行费用 | 系统调节、保障等按规则分摊的成本 | 当期科目、分摊依据、调整项 |
| 政府性基金及附加 | 按政策征收的项目 | 当期项目、征收范围与标准 |

不要把历史上出现过的基金名称直接拼成现行收费清单，也不要因套餐使用“全包价”字样就省略合同核对。

## 电能价格：通常是一条曲线

市场购电可能涉及中长期合同、现货结算或零售套餐。用户应付的电能费用，需要依据自己的合同和结算方式确定，并不总能简化为一笔现货成交。

对于可按分时单价与电量相乘的简化场景：

```text
电能量费用 = 各时段（结算电量 × 对应单价）之和
加权平均电能价格 = 电能量费用 ÷ 总结算电量
```

同样的分时价格，不同用电曲线会产生不同的加权均价。这也是为什么只比套餐的一个平均数字，容易漏掉负荷结构和合同风险。

## 输配电价：电度与容需量不要重复计算

两部制计费可从两个维度理解：

- **电度部分**与电量有关，常用元/kWh。
- **容（需）量部分**与计费容量或最大需量等有关，常见单位为元/(kVA·月)或元/(kW·月)。

账单中的“基本电费”通常与容需量计费相关。若已经在输配电费中计入同一项，就不能再加一次。计费方式的选择条件和计算口径应以适用规则为准。

功率 kW、容量 kVA 和电量 kWh 不是同一个单位。把需量单价直接与电量相乘，会造成数量级和含义都错误的结果。

## 其他费用也要核对包含关系

**售电服务费**可能单列，也可能反映在零售套餐中。已经包含在合同价格里的费用，不应重复叠加。

**功率因数调整电费**涉及相关计费考核，不应与电能量价格波动混为一谈。

**系统运行费用**和**线损费用**需要核对账单明细、适用期和分摊规则。不同月份费用变化，不一定来自售电公司提高了报价。

## 一个仅用于理解口径的算例

假设某用户当月电量为 10,000 kWh，并已按其适用口径拆出下表费用。以下金额全部为教学假设，不代表任何地区实际费率，也不构成电费报价。

| 项目 | 假设金额 |
| --- | ---: |
| 电能量费用 | 4,000 元 |
| 电度输配电费 | 1,500 元 |
| 容需量费用 | 1,000 元 |
| 线损费用 | 100 元 |
| 系统运行费用 | 200 元 |
| 基金及附加 | 200 元 |
| 合计 | 7,000 元 |

电能量部分的均价是 **0.40 元/kWh**，而总电费口径的综合单价是 **0.70 元/kWh**。它们并不矛盾，只是在回答不同的问题。

该算例假设没有其他单列服务费或调整项；实际账单应逐项核对，不能直接套表。

## 拿到账单，按这个顺序读

1. 确认用电类别、电压等级、计费方式和结算月份。
2. 核对表计电量、分时电量与计费容量或需量。
3. 分别标出电能、网络、线损、系统运行与基金项目。
4. 对照零售合同或代理购电公示，检查费用包含关系。
5. 最后再比较电能量均价与到户综合单价。

比较两家售电方案时，至少统一时段、电量曲线、税费及其他费用包含口径，还要读清偏差、联动和退出条款。

## 阅读小结

看电价，先问每一项在为什么付费，再问如何计算。读懂账单之后，前面讨论的市场、网络和主体关系，就有了一个可以实际核对的落点。
