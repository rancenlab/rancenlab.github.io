小周看到某日午间价格下降，便想得出结论：“以后中午一定最便宜。”第二天云层增加、设备检修，价格却发生了变化。

分析价格需要区分一次观察、可能原因和可验证证据。时间标签只是入口，不能代替供需与约束分析。

## 1. 先确认看的是哪一种价格

报价、出清价、结算价和零售套餐价不是同一个对象。日前与实时价格也不能混成一条未经说明的曲线。

每条价格记录至少带上日期、时段、市场、位置、单位、类型和版本。若数据源发生修正，历史图表也应说明使用的是哪个版本。

跨市场比较时，还要看是否含损耗、网络服务、税费或其他项目。口径不同造成的差额不能全部解释成供需差异。

## 2. 需求侧：同一时间有多少资源被需要

气温、生产班次和节假日可能影响负荷，但方向和幅度需要结合具体地区与用户结构判断。温度相同，不同湿度、工作日安排和工业负荷也可能形成不同需求。

分析时可以比较预测与实际负荷，查看偏差发生的时间。单看全天总量，可能错过晚间一两个紧张时段。

## 3. 供给侧：装机相同，可用能力可能不同

设备检修、故障、燃料条件以及风光资源变化会影响可用供给。铭牌装机容量不等于当时能够提供的增量出力。

假设需求维持 100 MW，而低报价机组可用能力减少 20 MW，系统可能需要更多高报价资源。价格上升的原因就不一定是用户多用了电。

反过来，低边际成本资源增加，也不保证用户账单立刻同比例下降，因为其合同与其他费用可能具有不同传导方式。

## 4. 网络与运行约束：有资源也未必能用到

某地区存在低价供给，但通道已受限，另一地区仍需调用较高成本资源。机组爬坡、备用需要和跨时段运行条件，也会影响短时选择。

因此，分析局部高价时，不能只展示全系统发电总量。需要核对相关位置能否获得足够供给，以及设备是否能够及时调整。

燃料、需求和网络等价格影响因素可参考 [EIA 的电价因素说明](https://www.eia.gov/energyexplained/electricity/prices-and-factors-affecting-prices.php)。这里借用的是分析维度，不把美国价格制度或燃料结构直接用于中国市场。

## 5. 用对照方法缩小解释范围

假设某时段价格从 400 升至 700 元/MWh，可以按顺序检查：

| 检查层 | 要找的变化 |
| --- | --- |
| 数据口径 | 是否同一位置、同一价格类型和单位 |
| 需求 | 预测或实际负荷是否增加 |
| 供给 | 低成本资源是否减少或退出 |
| 约束 | 网络或机组限制是否变化 |
| 规则与申报 | 限价、报价或结果处理是否变化 |

没有足够数据时，应把结论写成待验证假设，而不是用一张天气图解释全部波动。

## 6. 最后才计算对自己的影响

市场价格上涨多少，与工厂增加多少费用之间，还隔着用电曲线和合同。相同价格变化，对不同用户、不同合同的影响可能不同。

分析报告最好同时呈现市场事件、业务暴露和费用影响。前者说明发生了什么，中间说明哪些时段和数量与自己有关，最后才说明在明确模型下变化了多少钱。

## 自测

某日市场均价下降 10%，工厂电能量均价却上升，是否必然算错？不必然。如果工厂更多电量集中在高价时段，或合同联动方式不同，就可能出现这种结果。先核对加权方式与合同，再判断异常。
