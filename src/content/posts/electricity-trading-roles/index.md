启明零件厂发现账单电量与内部报表不一致。生产部门想找售电公司，财务想找供电服务人员，技术人员则提议询问交易机构。谁应该处理？

先不要只按公司名称分配问题。需要判断差异出在计量数据、合同算法、结算依据还是付款环节。看懂角色的关键，是把不同关系分开画。

## 1. 商业关系：谁与谁约定责任

在本系列的工厂场景中，工厂与售电公司签订零售合同。售电公司在批发侧作出购电安排，发电企业根据适用规则参与相应交易。

这并不意味着每个零售用户都与某家电厂形成一对一对应。售电公司可能管理多个用户、多个合同和多个时段的组合。零售约定与批发采购之间存在衔接，但它们不是同一份合同。

资源所有者和运营者也可能不同。工厂拥有储能，运营服务商负责优化，聚合商参与某项市场业务时，更要写清谁有控制权限、谁承担申报责任、收益怎样分配。

## 2. 物理关系：资源接在哪里

工厂的电能经接入的网络交付，计量点记录相应数据。发电机、储能和用电设备受到各自运行条件约束。

因此，合同变更不能自动改变设备接入关系；平台账户中新增一台设备，也不能证明它完成了现场接入、计量配置或安全要求。

一张合格的资源台账应同时保留商业主体与物理标识，例如资源所有者、运营授权、接入位置和计量点。只登记“某客户 2 MW”不足以支撑后续交易与执行。

## 3. 运行关系：谁提出要求，谁能够执行

市场运营涉及交易机构与调度机构，具体职责按相应规则划分。调度指令与普通业务系统里的计划建议有不同含义，接收、校验、执行、反馈需要明确责任。

用户侧也有内部边界。聚合平台收到需求后，不应跳过工厂的生产约束与授权机制，把所有设备视作任意可关停的开关。

2024 年《电力市场运行基本规则》区分经营主体、市场运营机构和提供输配电服务的电网企业等角色。该分类可作为阅读入口，但不能代替每一种业务的完整分工。[规则原文](https://zfxxgk.ndrc.gov.cn/web/iteminfo.jsp?id=20379)

## 4. 资金与数据关系：算出费用和完成付款是不同环节

计量数据、结算依据、账单和资金收付，是一条链上的不同对象。某个机构提供结算依据，不必然意味着所有钱都由该机构收付。

| 发现的问题 | 优先核对的证据 |
| --- | --- |
| 月电量不同 | 计量点、周期、倍率、数据版本 |
| 单价不同 | 合同条款、价格来源、适用时段 |
| 明细正确但合计不同 | 调整项、税费口径、舍入方式 |
| 账单无误但到账异常 | 收付款主体、日期、支付记录 |

小周应先整理差异对应的对象和数据，再按当地业务流程找责任方。这样比把同一个问题同时发给所有机构更容易得到有效处理。

## 5. 给业务画一张关系表

假设工厂委托一家企业管理储能，可以先写出下表。空白处就是业务尚未确认的事项。

| 关系 | 必须明确的问题 |
| --- | --- |
| 资产与授权 | 谁拥有设备，谁可以决定参与哪些业务 |
| 商业与履约 | 谁签约，谁承担不能交付的责任 |
| 接入与控制 | 通过什么系统接入，控制失败由谁处置 |
| 计量与核验 | 哪个计量边界证明执行结果 |
| 收益与付款 | 谁获得结算收入，按什么依据向各方分配 |

同一家企业可能承担多个角色，但每个角色的证据和责任仍应清楚。

## 自测

“系统里显示指令已发送，所以资源已经完成履约。”这句话缺少什么？至少还缺执行反馈、实际计量、规定的效果核验与结算确认。把角色与证据对应起来，才能从一个软件状态走到一项可确认的业务结果。
