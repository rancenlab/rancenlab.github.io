工厂合同中出现 0.40 元/kWh，月底把总电费除以总电量，却得到 0.69 元/kWh。两个数字不一致，未必意味着合同算错，因为它们可能使用不同费用范围。

本篇使用一张全部由假设数字组成的教学账单，学习核对方法，不提供任何地区的实际费率。

## 1. 先确认你在比较哪一种价格

交易价格描述某项市场交易的价格；零售合同价格或公式决定用户电能量等约定部分；到户综合单价则通常是选定总费用除以电量得到的结果。

比较时还要统一含税口径、服务费包含关系、时段、电压等级和计费方式。不同用户的综合单价不能脱离这些条件直接排名。

## 2. 用功能理解费用项目

电能量费用对应购电安排；网络相关费用对应输配服务；容量或需量相关部分可能出现在两部制计费中；线损、系统运行及基金附加等项目还需要按当期适用口径核对。

同一费用有时被归并展示，有时单列。账单显示方式与经济含义不能简单画等号，尤其不能把已经包含在输配费用里的基本电费再加一次。

具体输配标准应查询适用期文件。第四监管周期相关通知说明相应省级和区域价格自 2026 年 8 月 1 日起执行，实际使用需查看附件中适用地区和条件，不能继续把旧监管周期表格作为当前通用费率。[2026 年通知](https://www.ndrc.gov.cn/xxgk/zcfb/tz/202607/t20260710_1406431.html)

## 3. 一张可以逐项加总的假设账单

假设工厂当月使用 100,000 kWh。下表各项互不重叠，电能量费用已按合同计算完毕，其他金额只是人为设定。

| 项目 | 教学金额 |
| --- | ---: |
| 电能量费用 | 40,000 元 |
| 电度输配部分 | 15,000 元 |
| 容需量相关部分 | 8,000 元 |
| 线损费用 | 1,000 元 |
| 系统运行费用 | 3,000 元 |
| 基金及附加 | 2,000 元 |
| 合计 | 69,000 元 |

电能量均价为 0.40 元/kWh，到户综合单价为 0.69 元/kWh。两者差额来自其他已列费用，不应全部归为售电公司价差。

此表并非全国统一科目清单；实际可能存在服务费、功率因数调整、追补或其他适用项目，需检查是否已包含。

## 4. 固定或容量费用会改变综合单价

在本例基础上，再做一个单独假设：除 8,000 元容需量部分外，其余费用均随电量同比例变化，电量减少一半，计费容量或需量相关条件不变。

```text
新总费用 = (69,000 - 8,000) ÷ 2 + 8,000 = 38,500 元
新综合单价 = 38,500 ÷ 50,000 = 0.77 元/kWh
```

综合单价上升了，但总费用下降了，也没有假定任何收费标准上涨。原因是同样的 8,000 元分摊到了更少电量上。

因此，节电效果和单价变化要分别分析。不能看到综合单价上升，就认定节电没有价值。

## 5. 按顺序复核账单

先核对主体、月份、计量点和电量，再核对电能量合同公式，然后检查网络与其他费用的适用标准、计费数量和包含关系，最后才比较综合单价。

对于容需量项目，还要明确使用的是 kVA、kW 还是其他规定数量，以及计费周期。把元/(kW·月)直接乘 kWh，在量纲上就不成立。

## 自测

售电方案写着“每度电降低 0.02 元”，能否直接用总电费乘一个下降比例？不能。应确认降低的是哪一项单价、适用多少电量，以及其他费用和合同条款是否变化，再按相同负荷计算完整差额。
